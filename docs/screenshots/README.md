# Screenshots

Drop device captures here so the root README can show them.

## Suggested files

| File | Screen |
|------|--------|
| `overview.png` | Overview / dashboard (bottom tabs visible) |
| `battery.png` | Battery tab |
| `network.png` | Network detail (More → Network) |
| `sensors.png` | Sensors list or a live sensor stream |

## How to capture (device or emulator)

1. Install the [latest release](https://github.com/ScoobyDouche/PhoneDiagnosticTool/releases/latest) or a debug build.
2. Prefer **dark theme** for a consistent set (Settings → Appearance → Dark), or capture both light and dark if you want.
3. Use system screenshot (Power + Volume down), or Android Studio **Device Manager → camera icon**.
4. Crop to the app window only (no status-bar clutter if you can).
5. Target width ~1080px; PNG is fine.
6. Commit the four files above and push — the root README already references them.

Optional extras: `history.png`, `storage.png`, `tools.png`.
