# v1.1.2 — the About screen link actually opens now

Phone Diagnostic Tool **1.1.2** (versionCode **29**). One fix, reported from the field.

## Fixed

**Tapping the source-repository link on the About screen did nothing.**

It was styled as a link — primary colour, a URL for its text, sitting under a "Source" heading — but no click handler had ever been attached to it. It was decoration that looked interactive.

There were really two defects stacked on each other. The displayed string is deliberately scheme-less (`github.com/ScoobyDouche/PhoneDiagnosticTool`) because it reads better on screen, and `Uri.parse` on a scheme-less string yields a *relative* URI that resolves to nothing — so even a correctly wired tap would have failed just as silently. The full `https://` URL now lives in its own string, and the visible text stays short.

## Also

- The link is underlined, so it no longer relies on colour alone to signal that it is tappable.
- It gets a 48dp minimum touch target. One line of body text is well under that, which made it fiddly to hit even once it worked.
- Screen readers announce the action *and* read out the address, via `onClickLabel` rather than a `contentDescription` that would have replaced the URL.
- On a device with no browser — kiosk builds, some AOSP images — the URL is copied to the clipboard rather than the tap dying with no feedback.

The rest of the app was audited for the same pattern. This was the only dead link: `about_source_url` was the only URL string in the codebase, and the other `colorScheme.primary` text uses are chart line colours rather than link styling.

## Install

Download the `.apk` below, allow install from unknown sources, and open it. Requires **Android 8.0 (API 26)** or newer. Same signing key as previous releases, so it installs straight over 1.1.1.
