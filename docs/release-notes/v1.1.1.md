# v1.1.1 — per-app storage fixed on Android 11+

Phone Diagnostic Tool **1.1.1** (versionCode **28**). A patch release with one real fix.

## Fixed

**The per-app storage breakdown returned almost nothing on Android 11 and newer.**

Since API 30 the platform filters `getInstalledApplications()` down to packages the caller can already "see". The app declared neither `QUERY_ALL_PACKAGES` nor a `<queries>` element while targeting API 35, so **More → Storage** could list little beyond Phone Diagnostic itself — granting Usage Access appeared to do nothing, with no explanation on screen. Declaring `QUERY_ALL_PACKAGES` is the only way to enumerate installed packages for a genuine breakdown, so that is what this release does.

## About that permission

`QUERY_ALL_PACKAGES` is a restricted permission on Google Play and would need a justification form there. This app is distributed through GitHub Releases, where that review does not apply. The manifest carries a comment recording the decision so a future Play submission does not trip over it unaware.

The installed-app list is **read on demand, shown on screen, and never leaves the device** — verified rather than asserted: neither the report exporter nor the diagnostic log references the app-storage data, so it cannot reach an exported report or the rotating log. The README permission table and `PRIVACY.md` both document this.

It is an install-time permission, so there is no new runtime prompt to accept.

## Install

Download the `.apk` below, allow install from unknown sources, and open it. Requires **Android 8.0 (API 26)** or newer.

Same CI debug keystore as previous releases, so it installs straight over 1.1.0 without uninstalling. After updating, open **More → Storage**; if the list is still short, check that Usage Access is granted.
