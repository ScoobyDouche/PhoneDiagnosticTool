# v1.5.0 — Phone checkup, health score and a deeper privacy audit

Phone Diagnostic Tool **1.5.0** (versionCode **37**). Installs over 1.4.0 in
place. Two new permissions, neither of which shows a prompt: one restarts the
background monitor after a reboot, the other routes the earpiece test tone.

## New

- **Phone checkup** (More → Phone checkup) — the tests worth doing before
  buying or selling a used phone: touch grid, multi-touch, dead pixels,
  loudspeaker, earpiece, vibration, flashlight, volume buttons, proximity,
  light and motion sensors, charging port and headphones. Results go into the
  report you share.
- **Health score** on the Overview — 0–100, with every point it lost listed.
  Save a baseline and compare later, for example before and after a repair.
- **Real battery capacity** — measured from a normal 20 %+ charge, even on
  phones that hide the battery's health.
- **Crashes and restarts** (Shizuku / root) — what crashed, froze or rebooted
  in the last week.
- **Home-screen widget** — battery, temperature and RAM.
- **Hardware screen**, fuller sensor names and units, CPU core designs.

## Privacy

- New device checks: **user-installed CA certificates** (they can read your
  "secure" traffic), whether an organisation manages the phone, work
  profile, and **open Wi-Fi**.
- Apps exempt from battery optimisation are marked, and a summary says how
  many things are worth a look.
- With Shizuku / root: which apps can **draw over other apps, install apps or
  read your usage**, and which **used the camera, microphone or location in the
  last 7 days**.
- Fixed: reports could contain your router's IP address. They never contain an
  IP address now.

## Fixes

- Clearing a copied report silently did nothing once you had left the app; it
  now happens when you return instead.
- A hung Shizuku / root command could freeze refreshing.
- Load tests can be cancelled; network checks for IPv6, captive portals and a
  failing Private DNS.
