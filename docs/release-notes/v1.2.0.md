# v1.2.0 — optional elevated access (Shizuku / root)

Phone Diagnostic Tool **1.2.0** (versionCode **31**). Installs over 1.1.3 in place.

## What's new

A new **Elevated access** section in **Settings**. Some hardware values sit
behind sysfs permissions an ordinary Android app cannot get — the battery fuel
gauge is the headline one, which is why the capacity-health percentage reads
"unavailable" on so many devices. This release lets you opt into reading them,
and only if you choose to.

Three tiers:

- **Off** — the default. Nothing changes: no elevated reads, nothing bound, no
  extra process. The app stays a no-permissions diagnostic tool.
- **Shizuku** — small read-only commands run as the shell user (UID 2000), the
  same reach as `adb shell`. No root, and nothing permanent to the device. You
  install and start the [Shizuku](https://shizuku.rikka.app/) app once, then
  grant this app access with one tap. Settings shows whether Shizuku is
  installed, running, and has granted access.
- **Root** — the same read-only commands run through `su`, reaching nodes even
  the shell user cannot.

The chosen backend is used **only as a fallback** when the normal read is
denied, so devices that already expose a node are completely unaffected.

## First consumers

- **Battery fuel gauge** — the capacity-health percentage can now appear on
  devices that block those nodes from apps but allow the shell or root to read
  them. Still never estimated: if the gauge does not give both halves of the
  figure, the screen says so.
- **Per-core CPU clocks and frequency range** — recovered on devices that have
  locked `scaling_cur_freq` down to apps.

More consumers (GPU load, flash-wear estimates, `dumpsys`-backed detail,
full per-process RAM) can build on the same layer in later releases.

## A word on root

Rooting can trip a hardware fuse (Samsung Knox, for one) that permanently
disables secure features, and can break banking and wallet apps. That is your
decision to make — the app only ever reads, and the Settings copy says as much
before you pick it. Shizuku carries none of that cost.

## Privacy

Unchanged posture: everything runs on-device, and elevated commands are limited
to reading diagnostic values shown on screen. Nothing about this is transmitted
anywhere, and no elevated access is used or bound while the feature is Off. See
[PRIVACY.md](https://github.com/ScoobyDouche/PhoneDiagnosticTool/blob/main/PRIVACY.md).

## Install

Download the `.apk` below, allow install from unknown sources, and open it.
Requires **Android 8.0 (API 26)** or newer.
