# v1.3.0 — Connectivity, security and a quieter background

Phone Diagnostic Tool **1.3.0** (versionCode **33**). Installs over 1.2.1 in
place — no uninstall needed.

## New on the Overview

- **Connectivity & audio** — whether NFC and Bluetooth are present and on, and
  which kinds of audio device are connected right now (speaker, earpiece, wired
  or Bluetooth headphones, USB, HDMI…). It updates live, so plugging in
  headphones shows up within a few seconds. No new permissions are needed, and
  the Bluetooth name and address are never read.
- **Security** — verified-boot state (green / yellow / orange), whether the
  bootloader is locked, and whether storage is encrypted. Some phones hide the
  first two from apps; those show **Unavailable** rather than a guess.
- **Display** — now also lists the refresh rates the screen supports, its HDR
  formats (HDR10, HLG, Dolby Vision…) and wide colour gamut support.

All of it is included when you share or save a report.

## Fixed

- **Background battery drain.** The live refresh kept running every three
  seconds after you left the app — including the network latency probe and, if
  you left it on the Sensors screen, the sensors themselves. It now stops when
  the app goes to the background and picks up again when you return.
- **Storage read speed was optimistic.** The speed test reads back a file it has
  only just written, so part of it can come from memory instead of storage. The
  read figure is now labelled *may be cached* so it is not mistaken for what the
  flash itself sustains.

## Install

Download the `.apk` below, allow install from unknown sources, and open it.
Requires **Android 8.0 (API 26)** or newer. Same signing key as 1.2.1, so it
installs straight over it.
